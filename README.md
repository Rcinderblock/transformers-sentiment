# Transformers: Sentiment Analysis

Определение тональности англоязычных отзывов о фильмах: `0 — Negative`,
`1 — Positive`. Проект показывает токенизацию, скрытые состояния и внимание
DistilBERT, затем сравнивает два классификатора:

- исходный DistilBERT → CLS-вектор → логистическая регрессия;
- DistilBERT с дообучением всех слоёв и классификационной головы.

## Установка и полный запуск

Нужны Python 3.12 и доступ к интернету для первой загрузки данных и базовой модели.
Поддерживаются CPU, CUDA и ускоритель Apple MPS; устройство выбирается автоматически.

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py --day all
```

Программа скачивает модель и данные, создаёт графики, обучает оба классификатора,
сохраняет результаты сравнения и анализ ошибок. Дообучение выполняется 3 эпохи,
длина последовательности — 128 токенов, размер обучающего батча — 16,
скорость обучения — `2e-5`. Для выбора устройства передайте `--device cpu`,
`--device mps` или `--device cuda`.

## Этапы

Каждый этап запускается отдельно: `.venv/bin/python main.py --day N`.

| День | Что выполняется | Результат |
|---|---|---|
| 1 | Токенизация, специальные токены, дополнение и обрезка | `reports/tokenization.json` |
| 2 | Скрытые состояния, CLS-векторы, косинусное сходство | `reports/hidden_states.json` |
| 3 | Внимание разных слоёв и всех голов первого слоя | `reports/attention/`, `reports/attention_analysis.json` |
| 4 | Подготовка данных, CLS-признаки, LogisticRegression | `baseline_model.pkl`, `vectorizer.pkl`, `baseline_results.txt` |
| 5 | Дообучение, проверка после каждой эпохи, сохранение лучшей модели | `fine_tuned_model/`, `fine_tuned_results.txt`, `reports/training.json` |
| 6 | Предсказания и сравнение на общем test | `comparison_results.txt`, `reports/comparison.json`, две матрицы ошибок |
| 7 | Ошибки обоих типов, примеры, анализ длины | `error_analysis.txt`, `reports/error_summary.json` |

Этапы 5–7 используют результаты предыдущих. `app.py` запускает приложение
из сохранённой дообученной модели.

## Данные и сравнение

Используется воспроизводимая сбалансированная подвыборка
[IMDB](https://huggingface.co/datasets/stanfordnlp/imdb).
Основной набор: 2000 отзывов из исходного `train`, разделённых 80/20
с сохранением долей классов и `random_state=42`:
1600 для обучения обеих моделей и 400 для итогового тестирования.
Ещё 400 отзывов из независимого исходного пула используются для выбора эпохи.
Отзывы не пересекаются между тремя наборами; проверяются идентификаторы и тексты.

CSV с колонками `id`, `text`, `label` создаются в `data/`; состав и контрольные
суммы выборок сохраняются в `data/manifest.json`. Это небольшое учебное сравнение;
его метрики относятся к указанной подвыборке и обрезке до 128 токенов.

Базовая модель — [distilbert-base-uncased](https://huggingface.co/distilbert/distilbert-base-uncased).
Версии модели и датасета закреплены в `config.py`. Графики внимания относятся
к исходной модели; метрики классификации — к отдельному эксперименту обучения.

## Демо

Для запуска с готовыми моделями:

```bash
.venv/bin/python download_models.py
.venv/bin/python app.py
```

Модели загружаются из релиза этого репозитория; контрольная сумма архива
проверяется по `models.json`. В обычном Git находятся код, графики и отчёты.
Если модели уже обучены локально, запускайте приложение сразу:

```bash
.venv/bin/python app.py
```

Откройте [локальное приложение](http://127.0.0.1:7860).
Введите отзыв на английском: приложение вернёт класс и вероятности двух классов.
Нейтрального класса в этом датасете нет. Модель анализирует первые 128 токенов.
Обработка введённого текста выполняется локально.

Также доступны документация запросов по адресу `http://127.0.0.1:7860/docs`
и метод `POST /predict` с JSON `{"text": "This movie was absolutely fantastic!"}`.

## Результат сохранённого запуска

| Модель | F1 macro | Accuracy | Ошибок из 400 |
|---|---:|---:|---:|
| Исходные CLS-признаки + LogisticRegression | 0.7950 | 0.7950 | 82 |
| Дообученный DistilBERT | 0.8425 | 0.8425 | 63 |

Разница F1 — 0.0475, относительный прирост — 5.97%.
По validation выбрана эпоха 2 из 3. Полные метрики и матрицы ошибок —
в `reports/comparison.json`; примеры предсказаний — в `reports/demo_predictions.json`.
Наблюдения по реальным ошибкам — в `reports/error_observations.txt`.

## Проверки

```bash
.venv/bin/python -m unittest discover -s tests -v
```

Тесты проверяют разделение данных, отсутствие дублей, маски токенов,
размерности, обновление весов трансформера, метрики и соответствие классов.
Для проверок вычислений используется маленький случайно инициализированный
DistilBERT. Результаты эксперимента в `reports/` получены на настоящем
предобученном DistilBERT и отзывах IMDB.
